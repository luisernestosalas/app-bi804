# CRM con Clientes y Notas

Una aplicación CRM simple y eficaz para la gestión de clientes y sus notas asociadas, desarrollada con tecnologías web básicas.

## 🚀 Demo en Vivo

[Ver aplicación](https://app-bi804-5qy5hchu1-luisernestosalas-2775s-projects.vercel.app)

## 📋 Características

- ✅ Gestión completa de clientes (CRUD)
- ✅ Sistema de notas por cliente
- ✅ Interfaz intuitiva y responsiva
- ✅ Almacenamiento local del navegador
- ✅ Búsqueda y filtrado de clientes
- ✅ Diseño moderno y limpio

## 🛠️ Stack Tecnológico

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **Almacenamiento**: LocalStorage
- **Despliegue**: Vercel
