# Manual de Usuario - CRM App

## ¿Qué es esta app?

Es un sistema simple para gestionar clientes y tomar notas. Funciona en tu navegador web.

## Cómo acceder

1. Abre tu navegador
2. Ve a: https://app-bi804-5qy5hchu1-luisernestosalas-2775s-projects.vercel.app
3. La app se carga automáticamente

## Funciones principales

### 📋 Gestión de clientes
- **Ver clientes**: Lista de todos tus clientes
- **Añadir cliente**: Botón para crear nuevo cliente
- **Editar cliente**: Modifica información existente
- **Buscar cliente**: Encuentra clientes rápidamente

### 📝 Notas
- **Crear nota**: Añade notas a cualquier cliente
- **Ver notas**: Revisa historial de notas
- **Editar notas**: Modifica notas existentes

## Cómo usar

### Añadir un cliente nuevo
1. Busca el botón **"Nuevo cliente"** o **"+"**
2. Completa los campos:
   - Nombre
   - Teléfono
   - Email
   - Dirección (si aplica)
3. Haz clic en **"Guardar"**

### Crear una nota
1. Selecciona un cliente
