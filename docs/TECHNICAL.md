## Descripción del Sistema

Sistema de gestión de relaciones con clientes (CRM) desarrollado con tecnologías web frontend básicas. La aplicación permite la administración de información de clientes y la gestión de notas asociadas, proporcionando una interfaz web simple y funcional.
